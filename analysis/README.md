# Analysis areas

| Area | Intended use |
| --- | --- |
| `descriptive/` | Coverage, distributions, missingness, duplicates, and data-quality summaries |
| `supplier_analysis/` | Supplier identity, technology breadth, evidence status, and supplier-level summaries |
| `coordination_complexity/` | Bipartite network measures and transparent structural proxies |
| `statistical_analysis/` | Sensitivity checks and justified statistical or predictive experiments |

Outputs must retain links to the data version and code that created them. A machine-learning result is exploratory unless it uses a valid observed target, independent predictors, adequate sample size, and out-of-sample validation.
